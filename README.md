# 🛡️ Safe Scanner Ultimate

**أقوى أداة فحص أمني مجانية لنظام Windows، تجمع بين فحص الجهاز الشامل وكشف جميع أنواع الهاكات وأدوات الغش في ماينكرافت.**  
**النسخة الأسطورية – Ultimate Edition**

---

## 🌟 نظرة عامة

Safe Scanner Ultimate هو برنامج **قراءة فقط (Read-Only)**، لا يحذف ولا يعدّل أي ملف على جهازك. يتميز بقدرات فحص متقدمة منها:

- فحص شامل لملفات الجهاز والعمليات وعناصر بدء التشغيل.
- كشف الهاكات وحقن ماينكرافت (مودات، لانشرات، DLLs، عمليات، ذاكرة).
- تحليل الذاكرة الحي (Live Memory Scanner) للبحث عن نصوص الهاكات.
- قاعدة بصمات (Hashes) وقواعد توقيعات مرنة (Rules Scanner).
- كاشف التغييرات السلوكي (مقارنة لقطات للجهاز).
- لوحة تحكم برسوم بيانية، سجل فحوصات، تصدير HTML/JSON.
- وضع ليلي (Dark Mode)، شرح تفاعلي (Tooltips)، وأزرار فحص يدوي.

**صنع بواسطة:** `sh3la`  
**تم تطويره بواسطة:** `Rlue`

لتبويبات وطريقة الاستخدام
📊 تبويب Dashboard (لوحة التحكم)
يعرض إحصائيات آخر فحص: عدد العناصر عالية 🟡 متوسطة 🟠 منخفضة 🟢.

رسم بياني دائري (Pie Chart) وشريطي (Bar Chart) يوضّح توزيع النتائج.

أزرار سريعة:

🔍 فحص كامل – يبدأ فحصاً شاملاً للنظام.

🧩 فحص ماينكرافت – يبدأ فحصاً متخصصاً للعبة.

📂 فحص ملف/مجلد – يسمح لك باختيار ملف أو مجلد وفحصه يدوياً.

📁 فتح Downloads / Desktop – لفتح المجلدات المهمة مباشرة.

🛡️ تبويب "عام" (General Scanner)
يفحص جميع ملفاتك في المجلدات الأساسية (Downloads, Desktop, AppData, LocalAppData) بالإضافة إلى:

العمليات الجارية وعناصر بدء التشغيل.

إعدادات الريجستري (Run/RunOnce).

المهام المجدولة (Scheduled Tasks).

الاتصالات الشبكية النشطة.

التواقيع الرقمية (الملفات غير الموقعة).

قاعدة بيانات بصمات أدوات الحقن المعروفة.

الأزرار في هذا التبويب:

الزر	الوظيفة
🔍 ابدأ الفحص	بدء فحص كامل للمجالات المحددة
📂 فحص ملف/مجلد	اختيار ملف أو مجلد محدد لفحصه
📄 HTML	تصدير التقرير بصيغة HTML منسّقة
💾 JSON	حفظ التقرير بصيغة JSON
📋 نسخ المسار	نسخ مسار العنصر المحدد إلى الحافظة
🗑️ مسح	مسح النتائج المعروضة (لا يؤثر على الملفات)
🔎 (حقل بحث)	تصفية النتائج حسب أي كلمة
🧩 تبويب "ماينكرافت" (Minecraft Scanner)
أقوى ماسح متخصص في العالم للعبة ماينكرافت، يشمل:

فتح وتحليل ملفات المودات (JAR) والبحث عن حزم خبيثة.

كشف أسماء injectors الشهيرة (Vape, Sigma, Wurst, Meteor, Raven…).

فحص اللانشرات المثبّتة (Lunar Client, Badlion, Feather, إلخ).

فحص لقطات الشاشة (Screenshots) بحثاً عن أسماء مشبوهة.

كشف ملفات الإعدادات (config) الخاصة بأدوات الغش.

فحص حزم الموارد (Resource Packs) التي تحتوي كوداً خبيثاً (class/dex).

تحليل سجلات الأوامر والتشغيل (commandhistory.txt, latest.log) بحثاً عن javaagents.

كشف ملفات DLL/EXE المزروعة داخل مجلدات ماينكرافت.

فحص إعدادات البروكسي للنظام.

تعداد الحسابات المخزنة (Alt Accounts) مع تحذير.

فحص أدلة محذوفة (سلة المحذوفات/Prefetch) عن آثار أدوات غش قديمة.

🧠 مسح الذاكرة الحي (Live Memory Scanner) – يقرأ ذاكرة عمليات Java/Minecraft ويبحث عن نصوص الهاكات (مثل KillAura, FlyHack) بدون كتابة.

🧩 كشف مكتبات DLL المحقونة – يعرض المكتبات المشبوهة المحملة بواسطة عمليات ماينكرافت.

📸 تبويب "التغييرات" (Behavioral Change Detector)
📸 حفظ لقطة الآن – يحفظ لقطة لحالة الملفات والعمليات.

🔍 مقارنة باللقطة – يقارن الوضع الحالي باللقطة ويكشف:

ملفات جديدة ظهرت.

ملفات معدّلة (تغيّر حجمها).

عمليات جديدة تم تشغيلها.

يعمل كل شيء في الخلفية دون تجميد الواجهة.

📜 تبويب "History" (سجل الفحوصات)
يحفظ تلقائياً كل فحص تقوم به مع التاريخ والوقت.

يمكنك استعراض أي فحص سابق بنقرة مزدوجة.

زر تصدير كامل التاريخ إلى JSON لتصدير جميع الفحوصات دفعة واحدة.

يتم تخزين السجل في ملف scan_history.json بجانب البرنامج.

🎨 إعدادات إضافية
Dark Mode (الوضع الليلي): من شريط القوائم Settings → Toggle Dark Mode.

Tooltips (شرح تفاعلي): عند تمرير المؤشر فوق أي زر، يظهر شرح وظيفته.

🧠 الماسحات المتقدمة (خلف الكواليس)
قاعدة بيانات البصمات (Hashes): تتم مقارنة بصمة MD5 لأي ملف .exe/.dll مع قائمة أدوات حقن معروفة.

محرك التوقيعات (Rules Scanner): يبحث داخل الملفات عن نصوص وأنماط هيكس حسب قواعد معرفة مسبقاً (JAR تحتوي KillAura، DLL تحتوي Vape، إلخ). يمكن توسيع القواعد بسهولة.

⚠️ إخلاء المسؤولية والأمان
لا تقوم الأداة بحذف أو تعديل أي ملف، كل العمليات Read-Only.

لا ترسل أي بيانات عبر الإنترنت، كل شيء محلّي 100%.

لا تطلب صلاحيات مدير (Administrator) لكي تعمل (باستثناء بعض ميزات قراءة الذاكرة التي قد تحتاج صلاحيات محدودة وتعمل بأمان).

أي قرار بحذف ملف مشبوه يقع على عاتق المستخدم يدوياً بالكامل.

هذه الأداة للأغراض التعليمية والدفاعية فقط.
